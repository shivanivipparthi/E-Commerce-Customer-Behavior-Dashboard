# E-Commerce Customer Behaviour Analysis

## ⚠ Disclaimer: the dataset is synthetic and the project is an independent portfolio exercise

## Overview
An end-to-end data analytics project focused on analyzing customer behaviour, identifying trends, and generating actionable insights using Python, PostgreSQL, and Power BI.

## Dataset
A structured customer behaviour dataset used for data exploration, cleaning, and analysis.

## Tools & Technologies
- **Python:** Data cleaning and exploratory data analysis (EDA)
- **Pandas, NumPy, Matplotlib, Seaborn:** Data manipulation and visualization
- **PostgreSQL:** SQL queries and data analysis
- **Power BI:** Interactive dashboard development
- **Gamma:** Project presentation
- **Jupyter Notebook:** Analysis and documentation

## Project Workflow
1. **Data Loading:** Imported the dataset into Python.
2. **EDA:** Explored data distributions, patterns, and trends.
3. **Data Cleaning:** Handled missing values, duplicates, and inconsistencies.
4. **SQL Analysis:** Queried the cleaned data using PostgreSQL.
5. **Dashboard:** Built an interactive Power BI dashboard to visualize key metrics.
6. **Reporting:** Prepared a report summarizing findings and insights.
7. **Presentation:** Created a project presentation using Gamma.

## Dashboard
An interactive Power BI dashboard presenting key metrics, customer behaviour patterns, and analytical insights.

## Results
- Identified customer behaviour patterns and trends.
- Improved data quality through systematic cleaning.
- Extracted insights using Python and PostgreSQL.
- Presented findings through interactive visualizations and a structured report.

## How to Run
Review the Jupyter Notebook for Python analysis, execute the SQL queries in PostgreSQL, and open the Power BI dashboard in Power BI Desktop.

Python | SQL | PostgreSQL | Power BI | EDA | Data Cleaning | Data Visualization | Business Intelligence
